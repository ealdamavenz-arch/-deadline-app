Academic Deadline Coordination System - installable app (PWA)

1. Upload this whole folder to any HTTPS host (GitHub Pages, Netlify Drop, Vercel, or your school's web server).
2. Open the link on a phone:
   - Android (Chrome): menu > Install app / Add to Home screen
   - iPhone (Safari): Share > Add to Home Screen
3. For a real Android APK, paste the hosted link into pwabuilder.com and download the Android package.

Note: data is saved on each device (browser storage). A shared database needs the PHP + MySQL back end from Chapter III.
